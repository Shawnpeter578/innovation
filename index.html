class SevenStars:
  def __init__(self):
    self.minds = gather("creative")
    self.ideas = []
    self.projects = []
  def brainstorm(self, prompt):
    # The best ideas start as
    # the craziest questions
    idea = self.minds.collide(prompt)
    self.ideas.append(idea)
    return idea.refine()
  def ship(self, idea):
    proto = idea.build()
    proto.test()
    self.projects.append(proto)
    return "★ Shipped!"

What we do

Whatever we do, we do it to make a larger pie

Ideation Labs

Weekly brainstorm sessions where cross-disciplinary teams tackle wild prompts. No bad ideas, only unrefined ones. We teach structured creativity — SCAMPER, lateral thinking, constraint-based innovation.

Build Sprints

Month-long build cycles where teams go from concept to working prototype. Mentors from industry guide each sprint. Demo day at the end — pitch what you built, get real feedback.

Compete & Exhibit

We field teams at every major hackathon. We also host our own showcase each semester — Innovation Expo — where the campus sees what we've been building. Prizes, press, and recruitment follow.
